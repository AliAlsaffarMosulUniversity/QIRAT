# قيراط | QIRAT

نسخة ويب أولية عربية RTL بتصميم أسود وذهبي. افتح `index.html` في متصفح حديث.

## الوظائف
- إضافة وتعديل وحذف إعلان محلي لصلاة الجنازة.
- تحديد الجنس والجامع والموعد والمنطقة ورابط الخرائط.
- البحث والتصفية والمفضلة.
- مشاركة نص الإعلان، رموز QR تجريبية، ودعوة الأصدقاء.
- الوضع الليلي والنهاري، وصندوق ملاحظات الوقف.

## حدود هذه النسخة
لا يوجد خادم أو حسابات أو تحقق أو نشر عام أو إشعارات فورية. البيانات محفوظة في localStorage على الجهاز الحالي فقط. رموز QR تعتمد على مكتبة CDN وتحتاج اتصالاً بالإنترنت، كما أن روابط الإعلانات لن تعمل على أجهزة أخرى دون نظام استضافة وقاعدة بيانات. هذه نسخة MVP للواجهة والتفاعل وليست نظاماً جاهزاً لنشر أخبار الوفيات.

## المرحلة الإنتاجية
إنشاء backend مع PostgreSQL وواجهات API ونظام مراجعة الإعلانات والتحقق من صلاحية الناشرين وإشعارات push وخدمات الخرائط، ثم نشر التطبيق على HTTPS وتغليفه للهواتف والحاسوب.
